## 1. What was measured, and against what

**The instrument**: `node tools/elo.js --games=8000 --seed=1` (and
`--seed=2`). Every strategy in `tools/roster.js` — now **30** of them —
plays random 4-strategy lobbies of Hard (`berserker`) bots in **elemental**
mode. Each strategy gets ≈1050-1100 seats per seed. Bradley-Terry strengths
are fitted from **all** pairwise placements at once (order-free), then printed
on an Elo scale where **1500 = the roster average** and **+173 Elo ≈ a 73%
pairwise favourite**. `place` is the mean finishing position, 1-4 (lower is
better).

**Code state measured**: HEAD `5655ac3` (round 20.2, version string **r207**)
plus this session's `tools/roster.js` edits (§2) — i.e. the commit this report
lands in. Round 20 shipped, in order: anger `markEvery [20,15,10]` (was
[10,7,5]), ghost lv3 10 g (was 12), malady `auraR [10,14,18]` / `dotTime
[4,5,6]`, **every item flat 6 g or 8 g per level**, the **mosquito rework**
(no tax, every [6,5,4]th cast fires a pair; the Echo Stone item deleted and
merged in), and terra lv3 smashing pillars.

**The baseline it is diffed against**: the r200 table in
`docs/history/2026-08-09-strategy-elo-tournament.md`, same instrument, same
game count, 28 strategies, run before any round-20 number changed.

## 2. Roster changes made before this run (`tools/roster.js`)

Two edits, both to the strategy definitions only — no game numbers.

**(a) The deleted Echo Stone was purged.** Round 20.1 deleted the item;
`roster.js` still listed `echo` in the auto-pad FILLER list and in three
cores. Replacements, each inside its core's stated intent:

| where | was | now |
|---|---|---|
| FILLER (auto-pad list) | …hourglass, **echo** | …hourglass (six items) |
| `A2-items-mobility` | ended `hourglass3 → echo1` | ends `hourglass1 → 2 → 3` (explicit, same 78 g of mobility items) |
| `B6-item-breadth` | six items + echo, two levels each | all six items, all three levels, breadth-first; now `noPad` |
| `D7-stormcaller` | `…hourglass3 → echo1 → amulet2` | `…hourglass3 → boomerang1 → amulet2` (the echo gold became a second button for arcane's refund to shave) |

**⚠ A side effect worth naming**: with echo gone and round 20's flat item
prices, **the entire item shelf now costs 126 g** (sword/amulet/hourglass 8 g
× 3, boots/treads/cape 6 g × 3). That is *below* the roster's 150-185 g core
band, so an items-only core can no longer fill its own budget: the auto-padder
runs out of shelf. `node tools/roster.js` now says
`item shelf EXHAUSTED` instead of a misleading `⚠ UNDER` for
A1-items-sustain, A2-items-mobility, B5-item-depth, D8-juggernaut (126 g each)
and C1-bolt-rush (148 g). Those five seats therefore spend their last ~25-60 g
on the shared exhaust tail (which buys elements and spells), so **their
item-purity reads are diluted this round in a way the baseline's were not**.
Stated, not papered over.

**(b) A new family E: cooldown reduction.** Remi's request — he suspects CDR
stacking is secretly strong and untested. The two CDR axes in the game are
**arcane** (Ability Haste [18,32,32] on the *fireball only*, plus a lv3 that
refunds 1 s off every *other* cooldown per fireball hit — never its own) and
the **Hourglass** (haste [10,18,26] on *everything*). Haste **sums**, so both
maxed = 58 haste = a **÷1.58 fireball cooldown**.

- **E1-hastemaker** (157 g, Remi's specified order) — *"Cast faster, and every
  so often the cast is two balls."*
  Order: `arcane1 → mosquito1 → hourglass1 → arcane2 → arcane3 → mosquito2 →
  mosquito3 → lightning1 → boomerang1 → shield1 → lightning2 → boomerang2 →
  blink1 → lightning3`, then auto-pad (sword ×3, amulet ×2).
  Tests: CDR × fireball **throughput** — haste multiplied by mosquito's pair,
  with a pilotable kit for arcane lv3's refund to accelerate.
- **E2-chronomancer** (151 g, my design) — *"Five buttons, none of them ever
  off cooldown for long."*
  Order: `hourglass1 → arcane1 → hourglass2 → arcane2 → hourglass3 → arcane3 →
  lightning1 → boomerang1 → shield1 → rush1 → blink1 → shield2 → rush2 →
  blink2`, then auto-pad (sword ×3, amulet ×1).
  Tests: CDR × kit **width** — the same maxed haste core, but spent on five
  pilotable buttons and their cooldown levels, so arcane lv3's per-hit refund
  has the most cooldowns to shave.

Together with the pre-existing **D7-stormcaller** (arcane3 + hourglass3 +
lightning maxed = CDR × one-spell **depth**) these are three points on the
same axis: throughput, width, depth. Every spell named is one a berserker bot
actually pilots (verified in `pilotOwnedSpells`/`stepBerserker`: lightning,
boomerang, shield, blink as a lava save, rush natively, meteor only into a
CC hold).

`docs/ARCHETYPES.md` is generated from this file — regenerated here with
`node tools/roster.js --doc`.
